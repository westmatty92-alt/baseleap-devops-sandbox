# Discovery answers — Northside Plumbing Tech Job Board

Answered by Matthew, 2026-11-12, to docs/discovery-questions.md (all recorded as `decision` events on P0).

1. **Job card fields — 1A.** Title, customer name, customer phone, address, start time, notes.
2. **Job time — 2A.** One start time; the board lists jobs in time order.
3. **Statuses — 3A.** Scheduled / In progress / Done. The assigned tech changes status on their own jobs; the owner can change any job.
4. **Tech edit rights — 4A.** A tech edits only status and notes, and only on jobs assigned to them. Everything else is the owner's.
5. **Days — 5A.** Board opens on today; everyone can step to any past or future day; the owner can create jobs for any date.
6. **Owner rights — 6A.** Edit any field, reassign, cancel. Cancelled jobs stay on the board marked cancelled. No permanent delete.
7. **Accounts — 7A.** The owner adds each tech's email in the app; only listed emails can sign in, by emailed link (1 owner + 3 techs).
